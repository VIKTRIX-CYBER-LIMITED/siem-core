Vindex Agent

This installs the Vindex agent, which connects this Mac to your organisation's Vindex security console.

When the installer finishes, open Terminal and run the command from the console, for example:

sudo vindex-agent enrol VDX1.…

Then allow the agent full disk access in System Settings › Privacy & Security if your administrator has not already done so through device management.
