Thanks for installing the Vindex Windows Agent.

The agent connects this device to your organisation's Vindex security
console. If you installed it with an install code from the console, it
enrols itself and needs no further setup.

To check the agent:
  - Open "Services" and look for "Vindex Agent".
  - Agent log: C:\Program Files (x86)\ossec-agent\ossec.log
  - Configuration: C:\Program Files (x86)\ossec-agent\ossec.conf
